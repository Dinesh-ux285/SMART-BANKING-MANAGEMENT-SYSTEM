# 🏦 Smart Banking Management System

## 📌 Project Overview

The **Smart Banking System** is a Java-based console application developed using JDBC and MySQL to manage basic banking operations. It allows users to securely access their bank accounts and perform transactions such as depositing money, withdrawing money, transferring funds, and checking account balances.

The application interacts with a MySQL database through JDBC to store and manage customer account information and transaction records.

## ✨ Features

- **User Registration:** Create a new bank account.
- **User Login:** Authenticate users using their credentials.
- **Debit Money:** Withdraw money from an account.
- **Credit Money:** Deposit money into an account.
- **Money Transfer:** Transfer funds between bank accounts.
- **Balance Enquiry:** Check the current account balance.
- **Account Management:** Retrieve account details using registered email.
- **Database Integration:** Store and retrieve banking information using MySQL.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Database:** MySQL
- **Database Connectivity:** JDBC
- **IDE:** IntelliJ IDEA

## 🗄️ Database

The application uses MySQL to store and manage banking information.

The database manages information such as:

- Customer details
- Account information
- Account balances
- Banking transactions

## ⚙️ Application Workflow

1. Users can register by providing the required details.
2. Registered users can log in to their accounts.
3. After successful login, users can access banking operations.
4. Users can deposit, withdraw, or transfer money.
5. Users can check their available account balance.
6. All banking operations interact with the MySQL database through JDBC.

## 🚀 How to Run the Project

1. Clone this repository:

   ```bash
   git clone https://github.com/your-username/Smart-Banking-System.git
   ```

2. Open the project in IntelliJ IDEA or Eclipse.

3. Install and configure MySQL.

4. Create the required database and tables.

5. Add the MySQL Connector/J dependency to the project.

6. Update the database connection URL, username, and password in your Java configuration.

7. Run the main Java class.
